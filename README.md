## 🚀 Como Executar Localmente

### Pré-requisitos
- Docker & Docker Compose instalados
- Node.js / Python / PHP (de acordo com a stack)

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/unbook/](https://github.com/unbook/)[NOME_DO_REPOSITORIO].git
   cd [NOME_DO_REPOSITORIO]
    ```

2. **Configure as Variáveis de Ambiente:**
    ```bash
    cp .env.example .env
    ```

3. **Suba os containers da aplicação:**
    ```bash
    docker compose up -d
    ``` 
4. **Acesse no navegador:** `http://localhost:3000 (ou porta configurada)`.
